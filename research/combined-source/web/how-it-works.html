Three destinations / distinct assurance

Review. Sign. Verify.

Observe

Query an address. Display attributable slot/time and independent errors. Observation does not connect a wallet.

Review

Inspect every instruction, complete message and review context. Unsupported siblings refuse the whole action.

Authorize

On a qualified device, the wallet returns signed bytes. Compare message and verify signatures before RPC submission.

Retain

Keep a persistent event and separate observations. Submission, confirmation and local evidence are different claims.

Tasks and evidence

Create local tasks, track checklists, import files and preserve exact notes. Export manifests and receipts for independent inspection. Device capture and process recovery still need qualification.

Inspect a receipt locally

The inspector reads JSON in your browser and makes no network call. It displays recorded provenance; it does not cryptographically verify it. Run the independent offline CLI for signature and file integrity.
