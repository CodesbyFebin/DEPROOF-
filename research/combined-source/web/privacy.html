Local evidence

Imported files and task records stay in app-private storage. No evidence upload, location collection or AI transmission is enabled. System camera capture happens only when explicitly launched. Deleting a local record cannot retract an export already shared.

Network observations

RPC providers receive queried addresses, transaction signatures and explicitly approved devnet transaction bytes. Their response is an observation with source/freshness limits. Wallet authorization stays between the app and the installed wallet. Tokens are kept only in memory and excluded from exports.

Node control

Node keys use permission-restricted files, disclosed as software storage. Pairing authorizes selected scopes. Bandwidth is disabled by default and after restart. An owner-allowlisted receiver and explicit caps are required; local counters do not imply reward acceptance.

Retention and recovery

Android backup is disabled. Export public verification material and receipts intentionally. Evidence private keys are not portable and are never exported. Lost-device recovery does not recover wallet secrets or reverse transactions.
