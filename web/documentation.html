Reproducible setup

Build your own.

Android

./scripts/setup-android.sh
./gradlew assembleDebug testDebugUnitTest lintDebug

Requires JDK 17, Android SDK 37.0, build tools 36.0.0, dependency access and normal local socket permissions. The configured identity http://localhost is a local development identity; configure a developer-controlled HTTPS URL before release.

Local qualification

./scripts/qualify.sh
python3 scripts/qualify-core.py
./scripts/qualify-node.sh
python3 -m unittest discover -s tools

Offline integrity

python3 -m pip install -r tools/requirements.txt
python3 tools/verify.py receipt.json --files /path/to/private-files

Private files use stable manifest IDs as filenames. Missing files are NOT_RUN. The verifier does not query chain settlement or establish physical truth.

Owner-controlled node

node-agent/build/deproof-node --state /private/owner/node

Loopback TLS only. Copy the generated certificate through an owner-approved local channel and approve the node fingerprint. Pairing code expires after two minutes. Hosting/prover operations fail with named blockers until their runtimes qualify.
