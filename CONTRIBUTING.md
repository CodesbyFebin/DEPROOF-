# Contributing

Read docs/BUILD_DEPROOF.md and the authoritative master blueprint first. Preserve exact IDs and package identity. Implement dependency gates with executable tests and explicit provenance. Do not introduce custody, arbitrary node shell commands, permissive signing fallbacks, fictitious integrations or automatic mainnet spending.

Run scripts/qualify.sh and component scripts. Record blocked/device gates honestly. Add immutable byte mutation tests for protocol changes. Keep source assets, user work and failed-check evidence. Use separate file ownership for independent components and integrate schemas before parallel work. Never concurrently modify Android/registries.

PR descriptions should identify changed behavior, exact verification commands, limitations and source/licensing provenance. No push/deployment/release happens without separate authorization. Imported art rights remain unresolved; see docs/licensing.md.
